# Java Signal Analyser

A lightweight Java program designed to generate, simulate, and analyze different waveform signals.

## Features
- **Sine Signal**: Generates standard sinusoidal waveforms.
- **Square Signal**: Simulates periodic high/low step transitions.
- **Triangle Signal**: Produces linear rise and fall ramp patterns.
- **Noise Signal**: Introduces randomized signal noise.

## Project Structure
- `Main.java` - Driver class to execute the signal analysis and simulations.
- `SineSignal.java` - Implementation for sine wave generation.
- `SquareSignal.java` - Implementation for square wave generation.
- `TriangleSignal.java` - Implementation for triangular wave generation.
- `NoiseSignal.java` - Implementation for random/noise signal generation.

## Prerequisites
- Java Development Kit (JDK 8 or higher)
